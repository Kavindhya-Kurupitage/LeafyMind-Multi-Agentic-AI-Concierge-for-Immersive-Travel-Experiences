# Trip pack (PDF & email)

The **trip pack** combines Profile Builder output with all three planning agents into one branded deliverable for guests.

---

## When it unlocks

`trip_pack_ready = true` only when **all** of these have complete artifacts:

- `package_recommender` — `recommendations` non-empty
- `food_guide` — `must_try` non-empty
- `itinerary_planner` — `itinerary` days non-empty

The hub shows a progress checklist (1/3, 2/3) until then. Buttons **Download PDF** and **Email my plan** appear only when ready.

---

## Guest actions (UI)

On **Agent Hub** (`/hub`), section **Your trip pack**:

1. **Download PDF** — `GET /api/trip-pack/pdf` → browser download
2. **Email my plan (PDF)** — `POST /api/trip-pack/email` → Gmail SMTP with PDF attachment

Email is **on-demand** (button click), not automatic.

Requires **email on profile** (Profile Builder) and configured `GMAIL_SENDER_ADDRESS` + `GMAIL_APP_PASSWORD`.

---

## PDF contents

Generated by `backend/services/trip_pdf_service.py` (fpdf2):

- Leafy Cave header (logo from `frontend/public/logo.png` if present, else text brand)
- Travel profile summary
- Recommended packages (name, price, inclusions, fit reason)
- Food guide with **embedded local dish photos** from `/app/food_images`
- Day-by-day itinerary
- Footer with generation date

---

## Email types (do not confuse)

| Email | Trigger | Subject theme |
|-------|---------|---------------|
| **Trip plan PDF** | Guest clicks “Email my plan” | “Your Leafy Cave trip plan” + PDF attachment |
| **Feedback survey** | After all 3 planners complete (once) | “How was your LeafyMind experience” + link to Feedback Collector |

---

## API

| Endpoint | Description |
|----------|-------------|
| `GET /trip-pack/summary` | JSON for hub preview (works before ready) |
| `GET /trip-pack/pdf` | 400 if not ready; PDF bytes if ready |
| `POST /trip-pack/email` | 400 if not ready or no email; 503 if SMTP not configured |

---

## Configuration

```env
GMAIL_SENDER_ADDRESS=...
GMAIL_APP_PASSWORD=...
FRONTEND_URL=http://localhost:5174
PUBLIC_ASSETS_DIR=/app/public_assets
FOOD_IMAGES_DIR=/app/food_images
```

Optional: add `frontend/public/logo.png` for PDF header branding.
