# Leafy Cave logo assets

Place your official **Leafy Cave** logo file here:

- **`logo.png`** — preferred (used first everywhere in the app)
- **`logo.svg`** — premium fallback (included)
- **`leaf.svg`** — minimal favicon fallback

The `LeafyCaveLogo` component loads `logo.png` → `logo.svg` → `leaf.svg` automatically.
